Run it in one line

One binary. Your SMILES file. REST and MCP on 8080, gRPC on 50051.

docker run -p 8080:8080 -p 50051:50051 -v "$PWD/data:/data:ro" \
  ghcr.io/zhom/mossflux:latest serve --db chembl=/data/chembl_37_chemreps.txt.gz
curl -s https://api.mossflux.com/v1/similarity \
  -d '{"smiles":"CC(=O)Oc1ccccc1C(=O)O","threshold":0.6}' -H 'content-type: application/json'

curl -s 'https://api.mossflux.com/v1/substructure?smarts=c1ccc2[nH]ccc2c1&limit=5'
claude mcp add --transport http mossflux https://api.mossflux.com/mcp
grpcurl -import-path crates/mossflux-server/proto -proto mossflux.proto \
  -d '{"smiles":"CC(=O)Oc1ccccc1C(=O)O","k":5}' grpc.mossflux.com:443 mossflux.v1.Search/Similarity
  • Exact. Pruning is proved, never estimated. Every fast path is gated against a slow one.
  • Safe. No unsafe. Bad input is an error, a slow query hits its deadline.
  • Small. No chemistry library. Own SMILES and SMARTS parsers, perception and matcher.
