Similarity

Fingerprints packed into 64-bit lanes: one AND, one popcount and one integer compare per record. The arena is sorted by popcount, so the band is one contiguous slice and the rest is never read.

The band is weak where popcounts cluster. On ChEMBL-37 at 2048 bits it prunes 4.5x at t = 0.90, but only 1.6x at t = 0.70.

Substructure

Own SMILES and SMARTS parsers, aromaticity perception, a path-fragment screen, a per-molecule census and a VF2++ style matcher. No chemistry library underneath.

    Arthor's 30 to 50 billion per second is an aggregate over 96 threads.

    The same deck gives 0.9 to 1.2 billion per thread, and that is the only number compared here. Matching a per-thread rate is not beating a 96-thread aggregate.

    Read the molecules of each bit, not the bits of each molecule.

    Transposed, a query touches only its own set columns. Counts stay bit-sliced across a few plane bitmaps and ripple with XOR and AND, so nothing scatters into a counter array.

    About 6x over the linear scan at 2048 bits, hits byte-identical on every query. The first version did scatter, and lost by 2.6x at t = 0.70. Both results are in the repo.

    Nothing here is persistent, and one defect is open.

    Not built

    In memory only: no on-disk index, no write-ahead log, no compaction. No GPU, and no approximate search, by contract. The largest real corpus measured is 2.9M ChEMBL-37 molecules, not a billion.

    Exact means exact on the stored bits. A score of 1.0 means two identical bit vectors, not the same compound.

    Open defect

    The fingerprint generator records no provenance: no salt stripping, no useChirality, no Morgan parameters in the header.

    Tracked in docs/correctness.md. The hardening pass of 2026-10-03 fixed the other four, each with a regression test kept in the tree.

    Run it yourself

    One container serves the same API as the demo, on port 8080. Put the ChEMBL chemreps file in ./data first. 

    docker run -p 8080:8080 -v $PWD/data:/data ghcr.io/zhom/mossflux:latest serve --smiles /data/chembl_37_chemreps.txt.gz

    Deploy guide API reference Then open this page with ?api=http://localhost:8080.
