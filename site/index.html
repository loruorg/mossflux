Exact similarity search at billions of molecules per second.

mossflux searches molecular fingerprints by Tanimoto similarity and SMARTS substructure. It is written from scratch in Rust, and every result matches a brute-force scan.

Run it on your library.

Docker, x86-64

docker run -p 8080:8080 -v "$PWD:/data:ro" loruorg/mossflux \
  serve --db /data/library.smi

From source

cargo install --git https://github.com/loruorg/mossflux mossflux-cli
